📚 Book Vibe
A simple book reviewing platform where users can browse and review books.

🚀 Features
🔍 Book Browsing & Detailed View – Explore a collection of books and see detailed descriptions.

✍️ Add Reviews & Ratings – Share your thoughts and rate books you've read.

🎨 Clean UI – Styled with Tailwind CSS and DaisyUI for a modern look.

🔗 React Router Navigation – Seamless page transitions and navigation.

📱 Responsive Design – Optimized for both mobile and desktop devices.

🛠️ Working Procedure
Users can navigate through the site to explore books, view detailed information, and leave reviews.
✨ No login is required for browsing or reading reviews.

🧰 Technologies Used
React

React Router

Tailwind CSS

DaisyUI

React Icons
